# Compliance table

For each requirement in [requirements.md](requirements.md), this table gives the decision (section of [architecture.md](architecture.md) or [decisions.md](decisions.md)), the location in code, and the verification method. Verification is either an automated test (file and test name), a Storybook story (N8), or a manual check. Manual checks are marked as such and were not automated.

Commands used for verification: `npm run lint`, `npm test`, `npm run build`, `npm run build-storybook`, `npm run format:check`, and `npx tsc -b`.
